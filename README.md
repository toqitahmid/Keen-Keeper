# 🧠 KeenKeeper

## 📌 Project Name
**KeenKeeper**

---

## 📝 Short Description
KeenKeeper is a smart relationship and interaction tracker that helps you manage and monitor your contacts.  
You can log calls, messages, and video interactions, and view a structured timeline of all your communication history in a clean, modern UI.

It is designed to improve consistency in communication and help users stay connected with important people in their life.

---

## 🛠️ Technologies Used

- Next.js (React Framework)
- React.js
- JavaScript (ES6+)
- Tailwind CSS
- Radix UI (Tabs component)
- Lucide React Icons
- Context API (State Management)

---

## 🚀 Key Features

### 1. 📞 Interaction Tracking
Log and track different types of interactions like:
- Calls
- Messages
- Video calls

---

### 2. 📊 Smart Timeline View
View all interactions in a structured timeline format with:
- Type-based filtering
- Clean UI representation
- Chronological history tracking

---

### 3. 👤 Contact-Based Management
Each friend/contact has:
- Personal profile page
- Interaction history
- Communication goals and reminders
